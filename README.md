# INFP Earthquake Monitor

Aplicație Windows Electron care rulează direct interfața oficială Sistemului Alerta EWS de la INFP.

Aplicația nu mai face scraping și nu mai implementează un sistem propriu de detectare a cutremurelor. Site-ul INFP rămâne responsabil pentru:

- afișarea evenimentelor;
- detectarea evenimentelor noi;
- notificările Web/Windows;
- alegerea sunetului;
- CAPTCHA și permisiunile sale.

Electron oferă doar containerul Windows persistent și integrarea în system tray.
